# Flores amarillas

Pequeño jardín de flores animadas. Las flores aparecen y se desvanecen suavemente en posiciones aleatorias, con animaciones ligeras para móvil y escritorio.

## Uso

Abre `index.html` en un navegador o publica el repositorio con GitHub Pages.

## Créditos

Basado en la idea de [edu5975/flores-amarillas](https://github.com/edu5975/flores-amarillas); código adaptado para este proyecto.
